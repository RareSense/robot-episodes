# G1 in Isaac Sim

The G1 tasks rebuilt on Isaac Sim PhysX, AI-operated, following the recorded MuJoCo motion. Each task stands alone. Takes ran on GPU PhysX, except the tea bag take and the kettle lift, which ran on CPU PhysX.

`tools/` holds the import, live control, take and render scripts, and the per-task live fixes (`fix_<task>.py`). `live2.py` and `ops2.py` to `ops4.py` run a live session that renders its frames inside the sim process.
